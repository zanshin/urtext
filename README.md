# Name
An urtext edition of a work of classical music is a printed version intended to
reproduce the original intention of the composer as exactly as possible,
without any added or changed material.

# Purpose
Urtext is a static site generator (SSG) loosely patterned after Hugo. Creation
of this SSG served two purposes:

1. I wanted to have my own site generator
2. I wanted a real-world project to learn more about Rust

# Goals
- Rapid, incremental builds
- rsync to host
- Simple CSS

# Usage
List of commands:

- urtext create :: Create new content
- urtext build :: Rebuild the site locally
- urtext deploy :: Use rsync to copy the site to a server
- urtext new :: Generate a new site directory
