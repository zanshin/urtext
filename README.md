# Name
An urtext edition of a work of classical music is a printed version intended to
reproduce the original intention of the composer as exactly as possible,
without any added or changed material.

# Purpose
Urtext is a static site generator (SSG) loosely patterned after Hugo. Creating this
SSG serves two purposes:

1. I wanted to have my own site generator
2. I wanted a real-world project to learn more about Rust

# Usage
List of commands:

- urtext create
- urtext build
- urtext deploy
- urtext test
